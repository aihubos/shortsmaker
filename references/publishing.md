# YouTube 영상 제목·설명

이 단계는 실제 게시가 아니라 사용자가 복사해 붙여넣을 제목과 설명을 채팅에 출력하는 작업이다.

## 제목 자동 확정

씬 이미지가 완성된 뒤 다음을 수행한다.

- 후킹 관점과 문장 구조가 다른 YouTube 제목 후보 5개를 내부에서 만든다.
- 핵심 키워드를 가능한 앞부분에 배치한다.
- 영상에서 실제로 다루지 않는 결과를 약속하지 않는다.
- 다섯 후보 중 영상 내용, 후킹, 검색 명확성이 가장 좋은 1개를 자동 확정한다.
- 후보 목록이나 번호 선택을 사용자에게 요청하지 않는다.

## 썸네일과 최종 문구

1. 자동 확정한 YouTube 영상 제목과 대본에서 간결한 썸네일 문구 3개를 만든다.
2. 각 문구는 서로 다른 후킹 관점을 사용하고 기본 2~3줄로 구성한다.
3. 글자 블록은 가로 8%~92%, 세로 24%~72% 안에 두고, 중심은 세로 38%~45% 또는 55%~62% 중 빈 공간을 선택한다.
4. 최상단·최하단에는 글자를 배치하지 않으며 굵은 한글 글꼴, 강한 대비, 외곽선 또는 그림자를 사용한다.
5. 한글 철자, 390px 가독성, 잘림, 인물·핵심 오브젝트 보존을 확인한다.
6. 최종 썸네일 3장을 모두 보여준 뒤 아래 형식으로 출력한다.

```text
YouTube 영상 제목
<내부 비교로 자동 확정한 제목 1개>

YouTube 영상 설명
<문제와 영상의 가치를 전하는 첫 두 줄>

<영상에서 보여주는 내용 2~4문장>

<짧은 행동 유도>

<핵심 해시태그 3~6개>
```

설명에는 영상에서 실제로 다룬 내용만 포함한다. 타임스탬프는 실제 영상 구간과 일치할 때만, 출처·상표·AI 생성 콘텐츠 고지는 필요한 경우에만 넣는다.

## 저장과 게시 경계

- YouTube 영상 제목과 설명은 채팅에만 출력한다.
- `youtube/`, `title-options.txt`, `description.txt`, 해시태그·태그·업로드 안내 파일을 만들지 않는다.
- 최종 썸네일 3장만 프로젝트 `thumbnails/`에 저장한다.
- 문구 준비, 파일 저장, 실제 YouTube 업로드·저장·공개는 서로 다른 상태다.
- 실제 업로드나 공개는 사용자가 별도로 요청한 경우에만 수행한다.
