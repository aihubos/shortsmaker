# YouTube 제목·설명·썸네일

이 단계는 실제 게시가 아니라 사용자가 복사해 붙여넣을 제목과 설명, 선택한 문구의 썸네일 1장을 준비하는 작업이다.

## 제목 자동 확정

씬 이미지가 완성된 뒤 다음을 수행한다.

- 후킹 관점과 문장 구조가 다른 YouTube 제목 후보 5개를 내부에서 만든다.
- 핵심 키워드를 가능한 앞부분에 배치한다.
- 영상에서 실제로 다루지 않는 결과를 약속하지 않는다.
- 다섯 후보 중 영상 내용, 후킹, 검색 명확성이 가장 좋은 제목 1개를 자동 확정한다.
- 제목 후보는 사용자에게 선택시키지 않는다.

## 썸네일 문구 선택

1. 자동 확정한 제목과 대본에서 썸네일 문구 후보를 정확히 5개 만든다.
2. 각 후보는 서로 다른 클릭 동기를 사용하고 기본 2~3줄로 구성한다.
3. `1.`부터 `5.`까지 번호로 보여준다.
4. `원하는 문구 번호 1~5를 선택해주세요.`라고 요청하고 응답을 기다린다.
5. 사용자가 번호를 선택하기 전에는 썸네일을 생성하지 않는다.
6. 사용자가 선택하면 해당 문구로 완성 썸네일 1장만 만든다.

## 완성 썸네일 확인

- 글자 블록은 가로 8%~92%, 세로 24%~72% 안에 둔다.
- 중심은 세로 38%~45% 또는 55%~62% 중 핵심 피사체를 가리지 않는 곳을 선택한다.
- 굵은 한글 글꼴, 강한 대비, 외곽선 또는 그림자를 사용한다.
- 원본과 390px 화면에서 철자, 잘림, 가독성, 핵심 피사체 보존을 확인한다.
- 최종본 1장만 `thumbnails/01.png`로 저장하고 채팅에 보여준다.

## 최종 문구

썸네일 뒤 아래 두 항목을 각각 별도 `text` 코드블록으로 출력한다.

```text
자동 확정한 YouTube 영상 제목 1개
```

```text
문제와 영상의 가치를 전하는 첫 두 줄

영상에서 보여주는 내용 2~4문장

짧은 행동 유도

#핵심해시태그 #3개에서6개
```

설명에는 영상에서 실제로 다룬 내용만 포함한다.

## 저장과 게시 경계

- YouTube 제목과 설명은 채팅에만 출력한다.
- `youtube/`, 제목 후보, 설명, 해시태그, 태그, 업로드 안내 파일을 만들지 않는다.
- 실제 YouTube 업로드나 공개는 사용자가 별도로 요청한 경우에만 수행한다.
