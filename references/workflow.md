# ShortsMaker 자동 완성 워크플로우

## 1. 텍스트 먼저

주제와 길이를 기준으로 씬 구성을 내부에서 완성한다. 사실 확인이 필요하면 조사하되 별도 조사 파일을 만들지 않는다.

씬 01의 첫 문장은 시작 1~3초 안에 전달되는 강한 후킹으로 쓴다. 강한 질문, 반전, 결과 선공개 중 주제에 가장 적합한 하나를 선택한다. 후킹 앞에는 인사나 배경 설명을 넣지 않으며, 본문과 결말에서 반드시 회수한다. 사실을 왜곡하는 과장은 사용하지 않는다. 씬 01 이미지와 Flow 움직임도 같은 후킹을 첫 순간부터 보여준다.

각 씬을 다음 순서로 채팅에 출력한다.

```text
씬 01

나레이션
<해당 씬의 나레이션>

Flow 영상 프롬프트
<별도 text 코드블록에 영상 프롬프트>
```

- Flow 프롬프트는 씬당 하나다.
- Flow 코드블록에는 영상 생성에 필요한 문장만 넣는다.
- 모든 Flow 프롬프트에 `Audio: no narration, no dialogue, no voice-over, no spoken words.`를 넣는다.
- Flow는 해당 씬 이미지 1장을 시작 프레임으로 사용한다.
- 코드블록 안에 이미지 프롬프트, 파일명, 시간, 장면 목적, 설명 제목을 넣지 않는다.

모든 씬 다음에는 전체 나레이션을 이어 쓴 `text` 코드블록을 마지막으로 출력한다.

## 2. 최소 파일 저장

채팅 출력이 모두 끝난 뒤 `Youtube/<주제 기반 작업용 제목>/`을 만든다.

- `script.txt`: 마지막 전체 스크립트 코드블록과 동일한 내용
- `scenes/01.png`부터 씬 수만큼: 씬별 1장
- `thumbnails/01.png`~`03.png`: 후킹 문구가 포함된 완성 썸네일 시안 3장

이외 중간 파일이나 ZIP은 만들지 않는다.

## 3. 이미지와 썸네일 자동 완성

1. 씬별 첫 프레임 이미지 1장을 순서대로 생성한다.
2. 전체 씬의 피사체·환경·조명·색감을 일관되게 유지한다.
3. 영상 내용과 일치하는 YouTube 제목 후보 5개를 내부에서 비교하고 가장 강한 1개를 자동 확정한다.
4. 씬 이미지가 모두 끝나면 서로 다른 후킹 구도와 간결한 문구가 포함된 썸네일 시안 3장을 만든다.
5. 글자 블록 전체는 가로 8%~92%, 세로 24%~72% 안에 둔다. 중심은 세로 38%~45% 또는 55%~62% 중 핵심 피사체를 가리지 않는 곳을 선택한다.
6. 최상단·최하단에 글자를 두지 않고, 2~3줄의 굵고 대비가 강한 한글 문구를 사용한다.
7. 원본 크기와 390px 축소 화면에서 철자, 잘림, 가독성, 피사체 보존을 확인한다.

텍스트 출력이 끝나기 전에 이미지 생성 도구를 호출하지 않는다.

## 4. 최종 출력

1. 완성 썸네일 3장을 `thumbnails/01.png`~`03.png`로 저장하고 모두 보여준다.
2. 이어서 자동 확정한 `YouTube 영상 제목` 1개와 복사해 붙여넣을 수 있는 `YouTube 영상 설명`을 출력한다.
3. 제목 후보, 이미지 번호, 중간 승인을 사용자에게 요청하지 않는다.
4. 영상 제목과 설명은 별도 파일로 저장하지 않는다.
