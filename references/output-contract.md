# ShortsMaker 최소 결과물 규칙

## 저장 위치

```text
<현재 프로젝트 폴더>/Youtube/<주제 기반 작업용 제목>/
```

작업용 제목에서 `/`, `:`, 제어문자처럼 경로에 사용할 수 없는 문자만 `-`로 바꾼다. 같은 폴더가 있으면 `-v2`, `-v3`를 붙인다. 자동 확정한 YouTube 영상 제목으로 폴더를 이름 바꾸지 않는다.

## 허용되는 파일

```text
<작업용 제목>/
├── script.txt
├── scenes/
│   ├── 01.png
│   └── ...
└── thumbnails/
    ├── 01.png
    ├── 02.png
    └── 03.png
```

- `script.txt`는 전체 나레이션만 담는다.
- 씬 이미지는 씬마다 정확히 1장이다.
- 프로젝트에 저장되는 썸네일은 후킹 문구가 이미 들어간 완성 시안 정확히 3장이다.
- 필요하면 배경 이미지를 내부적으로 먼저 만들 수 있지만 문구 없는 중간 시안은 사용자에게 선택시키거나 프로젝트 폴더에 저장하지 않는다.
- Flow 프롬프트와 이미지 프롬프트는 파일로 저장하지 않는다.
- ZIP, SRT, 화면 자막, 연구, 타임라인, 게시정보 파일을 만들지 않는다.

## 채팅 출력 계약

씬 01은 첫 문장부터 1~3초 분량의 강한 후킹으로 시작한다. 후킹 앞에 인사나 배경 설명을 넣지 않고, 후킹의 질문이나 약속을 본문과 결말에서 회수한다. 씬 01 Flow 프롬프트도 같은 후킹 장면을 첫 순간부터 보여줘야 한다.

각 씬마다 다음 세 항목을 출력한다.

1. 씬 번호
2. 나레이션
3. 씬당 하나의 Flow 영상 프롬프트 코드블록

모든 Flow 프롬프트에는 다음 문장을 그대로 넣는다.

```text
Audio: no narration, no dialogue, no voice-over, no spoken words.
```

모든 씬 출력 뒤 전체 나레이션을 하나의 마지막 `text` 코드블록으로 출력한다. 이후 이미지 생성 단계로 넘어간다.

씬 이미지가 모두 끝나면 YouTube 제목 후보 5개를 내부에서 비교해 가장 강한 제목 1개를 자동 확정한다. 사용자에게 후보나 번호 선택을 요청하지 않는다.

이어 후킹 문구가 포함된 완성 썸네일 시안 3장을 보여주고 다음 두 항목을 채팅에 출력한다.

1. `YouTube 영상 제목`: 내부 비교로 자동 확정한 제목 1개
2. `YouTube 영상 설명`: 첫 두 줄의 문제·가치, 본문 2~4문장, 짧은 행동 유도, 핵심 해시태그 3~6개

## 썸네일 글자 안전영역

- 글자 블록 전체: 가로 8%~92%, 세로 24%~72%
- 권장 중심 위치: 세로 38%~45% 또는 55%~62%
- 최상단과 최하단 배치 금지
- 기본 2~3줄, 불가피할 때만 4줄
- 굵은 한글 글꼴, 강한 대비, 외곽선 또는 그림자 사용
- 핵심 피사체를 가리지 않는 위·아래 중앙 안전영역 선택
- 원본 크기와 390px 축소 화면에서 철자, 잘림, 가독성 확인
