# 쇼츠 썸네일 제작

이 문서는 사용자가 문구를 선택한 뒤 `thumbnails/01.png` 한 장을 만드는 단계에만 적용한다.

## 입력과 대표 장면

입력은 자동 확정한 YouTube 제목, 사용자가 선택한 썸네일 문구, 선택적으로 제공된 참고 이미지다.

1. 제목과 문구에서 `HOOK`, `SUBJECT`, `SURPRISE`, `NUMBER`를 찾는다.
2. 0.5~1초 안에 영상의 약속이 이해되는 결정적 순간 하나를 고른다.
3. 평범한 전체 사진보다 행동, 반전, 결과가 보이는 근접 장면을 우선한다.
4. 이미지와 문구가 같은 약속을 전달해야 하며 대본보다 과장하면 안 된다.

동물·곤충은 결정적 행동이 보이는 cinematic macro documentary, 음식은 commercial food photography, 과학은 documentary visualization, 우주는 cinematic science documentary, 기술은 premium product photography를 출발점으로 삼되 주제에 맞게 조절한다. 무조건 어둡게 만들지 않는다.

## 배경 이미지

- 이미지 생성 도구에는 한글, 숫자, 로고, 워터마크가 없는 **배경만** 요청한다.
- 한글을 이미지 생성 AI에 직접 그리게 하지 않는다. 생성 이미지의 가짜 글자도 허용하지 않는다.
- 주 피사체는 중앙~하단에 두고 메인 문구가 들어갈 세로 15%~50% 구간에 여백을 확보한다.
- 참고 이미지가 있으면 우선적인 visual reference로 사용한다.
- 참고 이미지를 9:16으로 늘여 찌그러뜨리지 않는다. crop, outpainting, background extension, subject repositioning을 사용하고 피사체의 외형·정체성을 보존한다.
- 최종 배경은 텍스트 합성 전에 직접 확인한다. 제목과 즉시 연결되는지, 피사체가 명확한지, 배경이 지나치게 복잡하지 않은지 본다.

## 문구와 타이포그래피

- 선택 문구의 글자, 숫자, 띄어쓰기, 문장부호를 바꾸지 않는다. 줄바꿈만 조정할 수 있다.
- 메인 문구는 의미 단위의 2~4줄로 나눈다. 긴 한 줄을 억지로 넣지 않는다.
- Pretendard ExtraBold/Black, Noto Sans KR Black, Gmarket Sans Bold를 우선하며 없으면 스크립트가 사용 가능한 굵은 한글 폰트를 찾는다.
- 기본은 흰색 글자, 검은 굵은 외곽선과 짙은 그림자다.
- 숫자를 먼저 강조한다. 다음으로 반전이나 위험을 전달하는 핵심 단어를 고른다.
- 강조색은 노랑, 주황, 빨강 계열 중 최대 2개만 추가해 화면 전체 색을 3개 이하로 유지한다.
- 숫자나 짧은 핵심어를 별도 줄로 두면 기본 글자보다 120%~150% 크게 만들 수 있다.
- 텍스트가 길면 자동으로 글자 크기를 줄이되 모든 글자·외곽선·그림자를 안전영역 안에 유지한다.

## 고정 캔버스와 안전영역

- 캔버스: 정확히 1080×1920, 9:16, RGB PNG, sRGB
- 좌우 여백: 각각 최소 70px
- 상단 여백: 최소 120px
- 하단 여백: 최소 160px
- 메인 문구 권장 구간: 세로 15%~50%
- 주 피사체 권장 구간: 중앙~하단 50%~55%
- 최상단에 글자를 붙이거나 피사체·행동의 시작점을 가리지 않는다.

## 결정적 합성 단계

텍스트 없는 배경이 준비된 뒤 다음 스크립트를 사용한다.

```bash
python3 <skill-dir>/scripts/render_thumbnail.py \
  --background "<텍스트 없는 배경 이미지>" \
  --text $'몸에서\n100도씨\n액체를 뿜는\n곤충이 있다..?!' \
  --highlight "100도씨" \
  --output "<프로젝트>/thumbnails/01.png" \
  --preview "/tmp/shortsmaker-thumbnail-preview.png"
```

- `--text`에 실제 줄바꿈 또는 `\n`을 넣을 수 있다.
- `--highlight`는 최대 두 번 사용한다. 생략하면 숫자와 대표 후킹 단어를 자동 탐지한다.
- `--align left`가 필요하면 지정하고, 기본은 중앙 정렬이다.
- 참고 이미지 crop의 중심을 바꿔야 하면 `--focus-x`, `--focus-y`에 0~1 값을 지정한다.
- 폰트를 직접 지정하려면 `--font`에 TTF, OTF 또는 TTC 경로를 넣는다.
- 미리보기는 `/tmp` 같은 임시 위치에 만들고 프로젝트에는 최종 `thumbnails/01.png`만 남긴다.
